Promo Finder

Finds 20–60 second promo clips in microdrama screenplays: a hook in the first 3 seconds, a cliffhanger at the cut, and a clip that makes sense to a first-time viewer.

Frozen results. This page displays the saved output of the Python pipeline run on the 50-episode input pack. It does not process new scripts itself — run python run.py all for that. Only short excerpts of the screenplay are shown.

How it works

  1. Parse every screenplay block (camera, action, sound, dialogue) with its original timestamp and speaker label; flag — never fix — bad timestamps and overlaps.
  2. Generate candidates two ways: shot-aligned windows (cut on camera boundaries, chosen by their ending) and event-anchored windows (open on a sharp line, a slap, an entrance). Never cut through a line of dialogue.
  3. Stage A — a cheap model screens every candidate, seeing only the clip's own blocks (no summaries, no later scenes). Code then checks its evidence: cited blocks must exist, the hook must sit in the first 3 s, the cliffhanger near the end.
  4. Stage B — a stronger model does a skeptical editorial pass on the best, uncertain and possibly-underrated clips: who is this about, what do they want, what's left unanswered, does the clip give its payoff away.
  5. Rank — hard gates (hook, cliffhanger, standalone), weighted score, overlap removal, then a separate posting order.
  6. Payoff-leakage check — only now does a model see what happens right after the clip, to catch cliffhangers that resolve instantly.
